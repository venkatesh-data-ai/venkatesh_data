# Supporting R Analysis

These scripts document selected analysis work from the capstone development process.

- `week4_run_method.R` — model execution and cross-validation workflow used during development.
- `week6_run_method.R` — model execution and comparative evaluation workflow.
- `plot_results.R` — result visualisation workflow.

The final capstone report describes the broader Python implementation and evaluation pipeline. The original binary `.RData` working files are intentionally excluded from this portfolio repository.
